# Lean coverage ledger

This page is the stable reader route for the book's Lean-coverage report. It
does not copy the derived theorem table. The structured authority is
`content/crouzeix_textbook/coverage.json`; the Rust publisher combines that
contract with a fresh compiled Lean receipt.

## Reading the generated ledger

Run `mise run crouzeix-textbook-publication`. The task compiles a fresh receipt,
publishes one immutable six-ledger generation, and then checks the same
generation without rewriting it.

The validated pointer is
`atlas/src/content/generated/crouzeix_textbook/publication/current.json`. Its
generation identifies `theorem_coverage_ledger.md`, which records each CFT
identity, publication and proof status, Lean mode, declaration locator, and
prose anchor. The pointer and output digests, rather than this guide, determine
which generated bytes are current.

## Interpretation boundary

A compiled declaration establishes its recorded Lean type in the pinned
environment. It does not by itself make a summary-level prose proof exact. Use
the [[knowledge/crouzeix_textbook/status_and_scope|status and scope]] page for
the current completion boundary and the
[[knowledge/crouzeix_textbook/claim_evidence_ledger|claim-evidence ledger]] for
source and review ceilings.
