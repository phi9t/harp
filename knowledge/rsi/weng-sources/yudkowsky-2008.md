# When the Object Level Rewrites Cognition

## Problem

The essay asks why AI development might change abruptly. Captured lines 17–45 divide the question into optimization slope, resources, and efficiency, then distinguish metacognitive, cognitive, metaknowledge, knowledge, and object levels.

## Core mechanism

Captured lines 63–71 define recursion as asking an AI to redesign a cognitive algorithm it uses. Installing the result collapses object-level problem solving into metacognitive optimization; lines 171–173 describe object-level output feeding metacognitive velocity.

## Reported evidence

This is a conceptual essay, not an experiment. Captured lines 141–189 use natural selection, culture, optimizing compilers, and EURISKO to discuss feedback and diminishing returns, without a controlled system or measured recursive result.

## Key limitation

Captured line 141 says the equations cannot describe a self-improving AI. Lines 177–191 allow near-zero progress or rapid acceleration depending on optimization power, opportunities, and diminishing returns, so the essay is not predictive.

## Why Weng cites it

Weng’s introduction, captured at evidence/weng/text/weng-harness.txt lines 24–30, uses the essay to define recursive self-improvement as intelligence improving its own cognitive machinery. Weng then broadens the editable system to training and deployment machinery; this is not a harness example.
