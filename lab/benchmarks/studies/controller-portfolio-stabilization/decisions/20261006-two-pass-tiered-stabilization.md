# Stabilize through a tiered two-pass process

Recorded: 2026-10-06

Controller portfolio stabilization uses a fail-closed two-pass process. Pass
one only inventories and preserves evidence. It never moves a ref, changes a
worktree, resumes a provider, or treats elapsed age as abandonment. Pass two
acts only through one separately reviewed action packet per controller effort,
and each landing, parking or retirement action requires human approval.

The Repository Stabilization Envelope covers every registered Corenius
worktree and durable effort, because focused controller work must not damage
unrelated ongoing work. Its record is deliberately light: identity, ownership,
branch and head, cleanliness, durable-effort relationship, preservation state
and next attention point.

The Controller Portfolio receives a complete operational-closure record that
also covers runtime bindings, provider sessions, tmux and processes, claims,
external effects, caches, artifacts and quarantines. Secret values are excluded.
