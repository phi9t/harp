## What to build

Use the qualified Scout Kit to observe one disposable Git source twice, seal both rounds outside the Git estate, compare generations and promote one strict-YAML Stabilization Evidence Record without mutating the source.

## Acceptance
- [ ] A reviewed source manifest pins the Git registry, exact read-only argv, collector identity, redaction rules and expected source generation.
- [ ] Both Observation Rounds write only to the mode-0700 external run root and are sealed before any record enters the evidence worktree.
- [ ] Stable input produces one schema-valid record with semantic ID; changed input produces explicit drift and blocks action.
- [ ] Fake credentials split across structured fields, argv-like text, chunk and truncation boundaries never reach persistent evidence.
- [ ] Independent verification proves the collector performed no claim, refresh, reconciliation, cleanup or Git mutation.
