## What to build

## Acceptance
- [ ] The strict Trial Template declares files/modes, deterministic Git history, refs, work items/blockers, tests, acceptance, fault hooks and expected identities.
- [ ] The factory owns Git configuration, identity/timestamps, locale, timezone, umask, traversal, Python identity, work-ledger ID allocation and atomic publication.
- [ ] Two materializations under the same toolchain have identical semantic seed identity while retaining distinct run paths and namespaces.
- [ ] Namespace collision, changed toolchain, partial construction, missing evidence, unresolved effects and unsafe cleanup fail closed.
- [ ] Repeated completed cleanup returns the same receipt, while interrupted cleanup reconciles owned resources before continuing.
