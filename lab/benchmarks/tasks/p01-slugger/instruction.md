`slugger.slugify(title)` must return a lowercase slug of letters, digits and single dashes: punctuation is dropped, runs of spaces and dashes become one dash, and leading or trailing dashes are removed. If nothing is left it returns `untitled`. Example: `" Q3: Core  API -- Audit! "` becomes `q3-core-api-audit`. Fix `slugger.py`; the project uses uv offline and has no dependencies.
