# Exercise map

This map assigns each seminar a diagnostic trace, two SICP exercises, and a transfer target. The diagnostic role is the rationale for doing the exercises: it names the distinction the reader should be able to observe. The transfer target names the corresponding systems invariant to formulate and test. The map intentionally contains no exercise solutions.
