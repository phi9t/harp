Workflow design and auto-research

Matching Weng section: Workflow Design. Read the public original.

Learner win

Distinguish an expert-designed research workflow from agent-program search, workflow-graph search, within-episode refinement, and generated training data.

Search needs four contracts

Declare the representation, proposal or mutation operator, evaluator, and archive or tree policy. ADAS proposes agent code directly. AFlow selects, expands, evaluates, and backpropagates scores through a workflow-search tree. The search procedure is not the task solver it searches for.

Paper production is also not identical to scientific discovery. A generated manuscript can document an experiment without establishing good problem choice, scientific taste, novelty, causal validity, or durable knowledge.

Source cards

  • AI-SCIENTIST is an expert-designed idea-to-experiment-to-paper workflow.
  • SCIENTISTONE is an expert-designed, evidence-grounded research workflow with a chain-of-evidence standard.
  • AUTODATA is an expert-designed synthetic-data workflow evaluated through downstream training.
  • ADAS uses a meta-agent to generate and select agent programs.
  • SELF-REFINE refines the current output using feedback within one episode; it does not persist a new workflow across episodes.
  • AFLOW uses Monte Carlo tree search over executable workflow graphs.

Card recall and adjacent discrimination

Card recall: Choose ADAS or AFlow. From memory, name its candidate representation, update operator, evaluator, and persistence structure.

Adjacent discrimination: A system critiques one answer three times, then discards the transcript. Another retains a workflow graph selected by held-out score. Which is within-episode refinement, and which is workflow search? What cost-matched control would you request?

Which system class uses MCTS to search retained executable workflow candidates?
