Learner win

Explain how an external procedure can improve fixed-weight behavior while separating activation, adherence, and outcome.

Same weights, different procedure

A harness can select context, call tools, externalize state, and route subproblems without changing model weights. Compare the same checkpoint under two matched harnesses to measure the procedure's contribution.

Possible internalization is a prediction, not a proven general law: a later weight update might preserve behavior after removing the external procedure. That requires a direct ablation. Tool and environment interfaces may remain external even when some procedure is learned.

Do not compress three boundaries

  1. Activation: was the relevant skill, memory, or procedure loaded or invoked?
  2. Adherence: did the agent continue to follow it?
  3. Outcome: did following it improve the task result?

HARNESS-DISENTANGLE separates harness updating from harness benefit and audits these use boundaries under fixed weights.
