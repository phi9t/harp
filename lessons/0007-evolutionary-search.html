Evolutionary search

Matching Weng section: Evolutionary Search. Read the public original.

Learner win

Classify an evolutionary system by edited object, population or archive, update operator, and evaluator without mistaking archive membership for promotion.

Population is not authority

Evolution supplies parent selection, mutation, evaluation, diversity, and archive policy. DGM's foundation model and outer evolutionary loop remain fixed while coding-agent repositories branch. A branching archive preserves lineage and possible stepping stones. It does not authorize deployment: external promotion still requires integrity and held-out checks.

The evaluator remains outside evolution. Search pressure amplifies its objective, including its gaps.

Four edited-object families

FamilySystemsWhat evolves
Prompt PROMPTBREEDER, GEPA Task or compound-system prompts; Promptbreeder also evolves mutation prompts, while GEPA retains a Pareto archive and uses reflective feedback.
Solution program ALPHAEVOLVE, SHINKAEVOLVE, THETAEVOLVE Algorithm or program candidates under executable evaluators; ThetaEvolve can optionally add reward-shaped weight training.
Harness DGM, HYPERAGENTS, DEMOEVOLVE Agent or harness code. Hyperagents uses one unified editable task-and-meta program. DemoEvolve uses demonstrations as diagnostic inputs; demonstrations are not its edited object.
Problem-specific weights LEARNING-DISCOVER, EPISTEMIC-DISCOVERY Test-time checkpoints or LoRA ensembles guided by continuous verifiers. These are not frozen program search.

Classify an unfamiliar system

A system keeps an island archive, asks an LM to mutate executable candidates, scores each with tests, and never trains the LM. Write four lines: edited object, population structure, update operator, evaluator. Then compare archive admission with production promotion and list one reason they must differ.

A method updates a LoRA ensemble at test time and uses verifier reward plus uncertainty. Which family fits best?
