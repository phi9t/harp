Future challenges and evaluation

Matching Weng section: Future Challenges. Read the public original.

Learner win

Classify research evidence by construct and state the ceiling beyond which its score cannot support a claim.

Challenges become promotion gates

Weng identifies weak or fuzzy evaluators, context and memory lifecycle, retention of negative results, diversity collapse, reward hacking, long-term maintainability, and human oversight. Treat these as separate checks rather than hiding them in one score.

A benchmark score is evidence about its declared construct. It is not by itself evidence of scientific taste, discovery, agenda choice, maintainable successor design, or recursive self-improvement.

Source cards

Eight sources, eight constructs

Autonomous-research attempt case report
NOT-SCIENTISTS provides failure-mode case evidence from four autonomous research attempts. It is not a benchmark or proof of autonomous discovery.
Expert-mediated science-collaboration report
GPT5-SCIENCE is a company-authored report of human-directed, expert-verified science collaboration case studies. It is not a benchmark or proof of autonomous discovery.
Paper replication
PAPERBENCH evaluates reproducing 20 AI papers against a detailed rubric.
Timed ML R&D
REBENCH evaluates frontier agents and human experts under fixed time budgets.
Offline Kaggle engineering
MLEBENCH evaluates ML engineering through private-leaderboard medal metrics.
Scientific Python and data workflow
SCIENCEAGENTBENCH evaluates planning, coding, execution, and self-debugging on scientific tasks.
Computational reproducibility
COREBENCH evaluates reproducing computational artifacts and passing task tests.
Correct and faster kernels
KERNELBENCH evaluates GPU-kernel correctness and speed against a baseline.

Classification and evidence ceiling

Classification: A benchmark gives an agent a published repository and asks it to recreate result artifacts that pass tests. Which construct is closest? What would distinguish it from paper replication scored by a manuscript-specific rubric?

Evidence-ceiling comparison: Compare a company case report about expert collaboration with a timed R&D benchmark. State one claim each can support and one shared claim neither can support.

A score requires functionally correct GPU code and runtime speedup over a baseline. Which construct is measured?
