Ghosthub

All your multiplexers. One native terminal.

Ghosthub is multiplexer-native across your Mac and SSH hosts. Create or attach to tmux, Herdr, and Zellij sessions with optional tmux-backed worktrees, keepalives, and automatic reconnect.

$brew install kenn-io/tap/ghosthub

macOS 26+ · Apple Silicon · View on GitHub

Features

All multiplexers

Bring tmux, Herdr, and Zellij sessions into one fleet across your Mac, SSH, and exe.dev. Each multiplexer keeps ownership of its own session world.

Managed worktree sessions

Create Git worktrees from new or existing branches, import GitHub pull requests, and manage their tmux sessions without leaving Ghosthub.

Powered by libghostty

The embedded libghostty terminal engine. Uses Ghostty's configuration format, with a dedicated Ghosthub config.

Featherweight

Native Swift with GPU-accelerated rendering. No Electron.
