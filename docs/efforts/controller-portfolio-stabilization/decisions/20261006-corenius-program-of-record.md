# Corenius is the controller program of record

Recorded: 2026-10-06

The owner selected Corenius as the program-of-record repository for persistent
multi-agent engineering coordination. Corenius owns the domain language,
controller contracts and accepted controller evidence. DevX owns developer
experience and typed remote access; Insula owns hermetic execution; sibling
repositories supply adapters, case studies and migration evidence rather than
independent controller products.

The retained SQLite controller (I2) remains the product core. The lead-driven
line (I1) is its operational proving ground and a source of mechanisms that
must be promoted with evidence. The PostgreSQL/Temporal line (I3) remains
parked under the existing SQLite-first supersession decision.
