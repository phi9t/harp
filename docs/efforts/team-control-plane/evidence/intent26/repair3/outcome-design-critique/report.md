Concrete implementation guardrails — inferred regression risks, not observed defects in the proposed design

1. Preserve the exact acceptance-receipt exception when adding terminal checks. ContractService::execute authenticates and checks generation/scope before mutation_enabled, then looks up its cached command (src/contracts.rs:228–253). A blanket rejection in mutation_enabled would break accepted outcome.accept replay. Conversely, moving every command lookup ahead of terminal policy would allow cached outcome.propose, verification.bind, production.verify and research.verify to bypass the proposal’s refusal. Only exact accepted receipt inspection gets the exception; new acceptance under another key still refuses. After amendment, retained history must preserve the old subject while old proof cannot accept the new current Intent. Keep the production candidate/report binding and latest-failed-gate logic outcome-specific (src/contracts/outcomes.rs:419–469), never replace it with a generic completion boolean.

2. Do not let a dispatch helper prohibit authorized intent.admit. lifecycle::amend currently calls kernel::task_dispatch_enabled (src/contracts/lifecycle.rs:67), which checks cancellation only (src/kernel.rs:381–395). Broadening that helper to reject accepted current work without separating amendment eligibility would block the very transition this proposal authorizes. Retain cancellation fences, permit the bounded explicit amendment, and reject new dispatch through the corresponding dispatch paths. Cached gateway/runtime preparation and journal inspection are separate from permission to launch (src/gateway.rs:387–425; src/episode_runtime.rs:327–391; src/temporal.rs:991–1002).

3. Classify authoritative mutation by operation and target, not merely caller credential shape. ArtifactService::execute/apply terminal guards cover candidate/report/policy mutations and must retain their exact Accept exception (src/artifacts.rs:377–404,663–664). In contrast, publish_evidence stores immutable bytes without attaching an authoritative candidate/report (src/artifacts.rs:284–307); retaining raw physical-effect evidence is compatible with closure. Do not apply a blanket artifact-storage prohibition that strands stop/log/usage proof.

Preserve exact event-bound retirement checks and unresolved usage blocking (src/supervisor.rs:1217–1305), including expiry and nullable original Attempt provenance.
