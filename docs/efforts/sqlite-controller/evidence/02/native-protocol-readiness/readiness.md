## Minimal registry and adapter contract (design inference)

Registry: server_id; topology; transport kind/endpoint; protected auth_ref (not raw bearer in SQLite/logs); runtime_incarnation + independent execution_handle; thread_store_id and persistent private home/store generation; binary/companion/catalog/config/schema pins and qualified capability set. Environment registry: server_id + environment_id; executor incarnation/identity-bound execution handle; WS endpoint + protected auth ref; workspace_id/generation; namespace/mount/policy digest; observed readiness. A reused environment ID is not a new executor's authority.

Binding: role/attempt, authority epoch, server_id/incarnation/store_id, thread_id, current_turn_id or explicit unknown, execution handle, workspace identity/generation, host/controlplane cwd, selected environment_id and remote cwd/roots. Thread IDs alone are never routing authority. Controller owns adapter endpoint and validates requests before dispatch. Worker model tools receive only thread/attempt-scoped controller grants. Raw shared app-server endpoint/auth is an operator capability, not a worker capability: it can address other threads and host RPCs. Native TUI is trusted operator input, never an independent worker scheduler.

Startup/recovery: acquire controller authority; inspect supervisor + storage identity; initialize pinned connection; register or verify correct executor; inspect/read exact thread; resume by ID; compare all returned binding fields; reconcile current turn/history before start. On changed server incarnation, block dispatch and UI input until this finishes. Treat lost RPC acknowledgement as unknown, inspect same binding, never blindly start another turn. Status queries do not establish process death. Preserve terminal events and independently observed execution outcomes separately.

Shared safe candidate: sterile independently supervised app-server+companion controlplane Insula, per-attempt native exec-server Insulas, role-scoped controller tool adapter, provider credentials outside all worker/controlplane mounts. Native executor registration uses WS, not a pathname socket; private-network production layout needs qualified fixed-endpoint Unix/socket bridges for both WS and provider SSE, or another explicitly isolated networking design. Whole-runtime separate option moves app-server+companion+thread store into each attempt boundary and needs the provider relay, but avoids remote-environment resume fallback as an authority escape. Shared controlplane store contains multiple thread histories and must never be exposed inside executors.

Question delivery 05/06: keep persisted/submitted-to-runtime/acknowledged-by-lead/resolved separate. Idle turn/start delivery or active turn/steer transport acceptance is not lead acknowledgement. Use durable question ID + attempt provenance; explicit scoped lead tool fetch/ack/answer establishes the latter states. Wrong expected turn returns pending; lost acknowledgement reconciles before repeat. Native dynamic-tool routing across multiple TUI/controller connections has not been qualified here.
