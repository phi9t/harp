# Mission: Crouzeix Lean Validation

## Why

Independently operate and audit the Crouzeix Lean-validation workflow, so a
formal-proof claim can be checked from pinned inputs through a clean build.

## Success looks like

- Explain the proof-validation pipeline without notes.
- Identify what a receipt establishes and what it does not.
- Run and audit a single formal-validation ticket safely.

## Constraints

- Learn from system-level concepts down to commands and Lean artifacts.
- Preserve the blind/reference-aware boundary.

## Out of scope

- Claiming mathematical correctness from a manuscript alone.
- Running live model search before its ticket boundary is ready.
